# Ветка `vlm-image-annotation` — разметка научных иллюстраций

Задача отдельная от бенчмарка верификатора: сгенерировать подробные английские
описания к каждой картинке набора, чтобы по ним потом работал SigLIP.

Инструмент написал Николай, здесь он выложен как есть плюс эта врезка.

## Что лежит

| Путь | Что это |
|---|---|
| `annotation_tool/` | сам инструмент: CLI, клиент OpenRouter, сборка промпта, раннер, состояние очереди, локальный просмотрщик |
| `run.py` | точка входа |
| `prompts/annotation_fewshot.md` | промпт с few-shot примерами |
| `examples/dku_reference.png` и `.txt` | размеченный вручную эталон, тот самый DKU из чата |
| `annotation_viewer/` | веб-интерфейс для ручного одобрения описаний |
| `annotation_docs/` | руководство пользователя, архитектура, перенос на другую машину |
| `ANNOTATION_README.md` | исходный README инструмента |
| `tests/test_annotation_tool.py` | тесты |

## Быстрый старт

Набор PNG кладётся рядом, в папку `nikolay_ai_360_student`. Ключ OpenRouter — в
`.env` (скопировать из `.env.example`), в репозиторий он не попадает.

```powershell
python run.py validate
python run.py run --limit 5 --workers 2 --max-pending-review 4
```

Браузер откроется сам. Ответ модели сохраняется рядом с картинкой, окончательное
описание появляется только после одобрения человеком.

Подробности — в [annotation_docs/USER_GUIDE.md](annotation_docs/USER_GUIDE.md).

## Модель и стоимость

По умолчанию в CLI стоит `openai/gpt-5.6-sol`. Это одна из самых дорогих
мультимодальных моделей в OpenRouter: $2.50 за миллион входных токенов и $15.00
за миллион выходных.

|---|---|---|---|

| `qwen/qwen3-vl-235b-a22b-instruct` | $0.210 | $1.900 | $0.29 |
| `google/gemini-3.7-flash` | $0.375 | $1.875 | $0.33 |

Разница между крайними вариантами на всю работу — около двух с половиной
долларов, так что выбирать стоит по качеству описаний, а не по цене. Проверить
качество можно прогоном одной пачки через несколько моделей и сравнением с
`examples/dku_reference.txt`.

Модель задаётся флагом:

```powershell
python run.py run --model google/gemini-3.7-flash --limit 5
```

## Про ключ

**Ключ у команды общий.** Расход виден в
<https://openrouter.ai/credits>, и прогоны разных людей уменьшают один и тот же
баланс. Если нужен отдельный лимит, его можно выставить ключу в настройках
OpenRouter.

Проверить остаток:

```powershell
python -c "import re,httpx;from pathlib import Path;k=re.search(r'OPENROUTER_API_KEY\s*=\s*(\S+)',Path('.env').read_text(encoding='utf-8')).group(1);d=httpx.get('https://openrouter.ai/api/v1/credits',headers={'Authorization':'Bearer '+k},timeout=60).json()['data'];print('осталось: $%.2f'%(d['total_credits']-d['total_usage']))"
```

## Связь с основной работой

Ветка [`zhenya`](../../tree/zhenya) содержит бенчмарк VLM-судьи: набор из 201
четвёрки, тринадцать версий промпта судьи и ансамбль из двух судей с детекцией
61%. Задача там другая — проверять достоверность иллюстраций, а не описывать их.
Общее только то, что картинки берутся из одного источника `verifier_v0`.
