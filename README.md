# VLM Verifier Benchmark

> **Ветка `zhenya`.** Здесь лежит подобранный набор из 201 четвёрки (`bench/`),
> восемь версий промпта судьи с замерами и инструменты статистики.
> Начинать с [docs/handoff/HANDOFF.md](docs/handoff/HANDOFF.md).

Воспроизводимый бенчмарк для проверки того, насколько визуально-языковые модели
(VLM — модели, работающие одновременно с изображениями и текстом) находят
контролируемые ошибки в научных иллюстрациях. Для каждой пары независимо
проверяются исходная и изменённая картинки. По умолчанию используются 243
искажённые пары ML-поднабора `verifier_v0`.

В репозитории есть код, промпты, тесты, HTML-просмотрщик, документация и
`AGENTS.md`. Сам набор данных, архивы данных, ключи и результаты запусков не
публикуются.

## Подготовка набора данных

Получите `verifier_v0` из разрешённого вам источника и распакуйте его в
каталог проекта так, чтобы существовал файл:

```text
data\data\verifier_v0\manifest_ml_l2_fail.jsonl
```

То есть PNG-файлы должны лежать, например, по пути
`data\data\verifier_v0\figures\ml_l2_fail\document_1\figure_2.png`.
Если набор передан ZIP-архивом с такой структурой, из PowerShell в корне проекта
выполните:

```powershell
Expand-Archive -LiteralPath C:\путь\к\verifier_v0.zip -DestinationPath .\data
```

После распаковки проверьте расположение командой
`python -m vlm_bench validate-dataset`. Каталог `data/` намеренно исключён из
Git; не добавляйте в репозиторий изображения, манифесты или их архивы.

## Установка

В PowerShell из корня проекта:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e .
Copy-Item src\.env.example src\.env
```

Для реальных запросов впишите ключ в `src/.env`:

```text
OPENROUTER_API_KEY=ваш_ключ
```

Ключ не попадает в артефакты запусков и не должен добавляться в Git.

## Проверка и HTML-просмотрщик без сети

Эти команды не отправляют запросы в OpenRouter:

```powershell
python -m vlm_bench validate-dataset
python -m vlm_bench render-prompt --id document_1/figure_2
python -m vlm_bench run --dry-run --limit 1
python -m vlm_bench viewer
```

Команда `viewer` запускает локальный сервер, который предоставляет HTML-интерфейс
для просмотра каталога `runs/`. Откройте <http://127.0.0.1:8080>: в нём можно
выбрать запуск, отфильтровать пары и открыть рядом исходную и изменённую
картинки, ответы модели, запрос, промпт и метаданные. Просмотрщик работает
только на компьютере пользователя, ничего не изменяет и не публикует результаты.
Остановить его можно `Ctrl+C`.

Для другого порта используйте:

```powershell
python -m vlm_bench viewer --port 8081
```

## Реальные запуски

Перед первым сетевым запуском убедитесь, что команда `render-prompt` показывает
нужный текст и картинку. Каждая пара создаёт два независимых параллельных
запроса: `orig` и `fail`; их контексты не смешиваются.

```powershell
# Один заранее подготовленный реальный тест. Флаг --live обязателен.
python tests\manual_openrouter_one_pair.py --live

# Первые 10 пар с понятным названием запуска.
python -m vlm_bench run --limit 10 --name "Базовый промпт — первые 10"

# Точные пары в порядке пользователя.
python -m vlm_bench run --id document_1/figure_2 --id document_5/figure_3

# Список пар: одна строка — один pair_id.
python -m vlm_bench run --ids-file batch.txt

# Выбор по пути к одной из двух картинок пары.
python -m vlm_bench run --image-path data\data\verifier_v0\figures\ml_l2_fail\document_1\figure_2.png --name "Проверка Figure 2"
```

По умолчанию один вызов может сгенерировать до 16 384 выходных токенов: этого
достаточно и для рассуждения, и для JSON-аудита. При необходимости параметр
можно изменить явно, например `--max-tokens 24000`.

Обычный запуск не имеет денежного предела по умолчанию. Если нужен контролируемый
предел расходов, задайте его явно: `--max-cost-usd 5`.

Реальный ручной тест использует одну пару `document_1/figure_2`, создаёт два
запроса и устанавливает предел стоимости 1 USD. Он не запускается обычными
тестами автоматически.

Новый запуск всегда создаёт отдельный каталог в `runs/`. Если реальный запуск
прерван, продолжите его, подставив путь, напечатанный в конце предыдущей команды:

```powershell
python -m vlm_bench resume runs\<имя_запуска>
```

Просмотрщик показывает название из `--name` в списке запусков. Старые запуски,
у которых названия нет, отображаются по техническому идентификатору каталога.

сервер просмотрщика; сетевых обращений и расходов нет.
