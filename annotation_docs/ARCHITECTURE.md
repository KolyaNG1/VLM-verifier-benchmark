## Самодостаточность

Программа не зависит от исходного репозитория. Ей нужны только собственная
папка, соседний каталог `nikolay_ai_360_student`, Python 3.11+ и, для реальных
вызовов, ключ OpenRouter. Все используемые библиотеки входят в Python.

`run.py` — единственная точка входа. Он определяет родительскую папку самой
программы как общий корень, поэтому относительные пути одинаково работают у
разных разработчиков.

## Основные модули

| Путь | Назначение |
|---|---|
| `annotation_tool/cli.py` | Команды `validate`, `run`, `serve` и параметры. |
| `annotation_tool/prompting.py` | Чтение Markdown-промпта, прикрепление ручных примеров и PNG без передачи путей модели. |
| `annotation_tool/openrouter.py` | Загрузка `.env`, запросы и повторы OpenRouter. |
| `annotation_tool/runner.py` | Параллельные исполнители и ограничение очереди ручной проверки. |
| `annotation_tool/state.py` | Атомарная запись JSON, статусы карточек и соседние файлы ответов модели. |
| `annotation_tool/viewer_server.py` | Локальный HTTP-сервер, выдача картинок и API решений человека. |
| `viewer/` | Автономный интерфейс браузера, Markdown и темы. |

## Жизненный цикл карточки

```text
queued → generating → awaiting_review → approved
                     │        │
                     │        └─ reject → queued
                     └─ manual save → approved
```

- При `generating` один из исполнителей отправляет изображение в модель.
- Полученный текст сразу записывается как `figure_M.vlm_attempt_NNN.md` рядом
  с PNG и становится `awaiting_review`.
- При `approved` итоговое описание записано в `figure_M.txt`.
- Человек может вручную сохранить текст из любого состояния; поздний сетевой
  ответ тогда игнорируется и не может перезаписать ручной результат.

## Команды и параметры

```text
python nikolay_ai_360_annotation/run.py validate
python nikolay_ai_360_annotation/run.py serve
python nikolay_ai_360_annotation/run.py run [параметры]
```

Полезные параметры `run`:

| Параметр | Назначение |
|---|---|
| `--limit N` | Размер текущего пакета. |
| `--offset N` | Сколько подходящих изображений пропустить перед пакетом. |
| `--workers N` | Число одновременных запросов. |
| `--max-pending-review N` | Максимум ответов, ожидающих человека. Должен быть не меньше числа исполнителей. |
| `--model ID` | Идентификатор модели OpenRouter. По умолчанию `openai/gpt-5.6-sol`. |
| `--port N` | Порт локального просмотрщика, по умолчанию `8765`. |
| `--dry-run` | Создать тестовые кандидаты без сети и расходов. |
| `--state-file PATH` | Относительный путь к JSON состояния. |
| `--artifacts-dir PATH` | Относительный каталог технических артефактов просмотрщика. |

По умолчанию состояние размещается в соседнем каталоге
`nikolay_ai_360_annotation_artifacts/`. Ответы модели всегда размещаются рядом
с PNG и не зависят от этого параметра.
