# Руководство пользователя

[← К документации](index.md) · [← К README](../README.md)

## Что нужно заранее

- Python 3.11 или новее, доступный по команде `python`.
- Браузер.
- Доступ в интернет и ключ OpenRouter для реальной генерации.
- Соседняя папка с PNG `nikolay_ai_360_student`.

Программа использует только стандартную библиотеку Python; устанавливать пакеты
через `pip` не нужно.

## Правильное расположение папок

Распакуйте программу так, чтобы обе папки имели одного родителя:

```text
рабочая_папка/
├── nikolay_ai_360_student/
│   ├── ml_orig/
│   ├── juri_orig/
│   └── golden/
└── nikolay_ai_360_annotation/
    ├── run.py
    ├── .env
    ├── examples/
    └── docs/
```

После первого запуска рядом автоматически появится
`nikolay_ai_360_annotation_artifacts/`. Не переносите этот каталог в папку с
кодом: это рабочее состояние конкретного запуска.

## Настройка ключа

Откройте `nikolay_ai_360_annotation/.env` и впишите ключ:

```env
OPENROUTER_API_KEY=ваш_ключ
```

Не публикуйте `.env` и не отправляйте его другим людям. При передаче программы
оставьте файл пустым либо удалите его; получатель создаст свой по
`.env.example`. Системная переменная `OPENROUTER_API_KEY`, если она задана,
имеет приоритет над значением в `.env`.

## Проверка перед расходами

Из `рабочая_папка` выполните:

```powershell
python nikolay_ai_360_annotation/run.py validate
```

Команда проверяет, что существует ручной пример DKU, его описание и все нужные
пути. Она не использует ключ и не обращается к сети.

## Первый запуск на пяти изображениях

```powershell
python nikolay_ai_360_annotation/run.py run --limit 5 --workers 2 --max-pending-review 4
```

- `--limit 5` — взять пять картинок.
- `--workers 2` — одновременно отправлять не более двух запросов.
- `--max-pending-review 4` — остановить новые запросы, когда четыре ответа ждут
  человека. Это ограничивает расходы до проверки качества первых результатов.

Откроется `http://127.0.0.1:8765`. В правой колонке находится очередь, слева
видны картинка, форматированный ответ модели и поле для правки.

Для каждой карточки выберите один вариант:

1. Исправьте текст при необходимости и нажмите «Одобрить отредактированный
   ответ». Итог станет `figure_N.txt` рядом с изображением.
2. Напишите причину и нажмите «Отклонить и переделать». Карточка вернётся к
   модели, а комментарий добавится к следующему запросу.
3. Полностью замените текст и нажмите «Сохранить вручную». Это работает в любой
   момент, даже без вызова модели.

Остановить сервер можно `Ctrl+C`. Все действия сохраняются сразу, поэтому
после остановки ничего не теряется.

## Продолжение и следующие пакеты

Открыть уже сохранённую очередь без новых запросов:

```powershell
python nikolay_ai_360_annotation/run.py serve
```

Следующие пять ранее не выбранных картинок:

```powershell
python nikolay_ai_360_annotation/run.py run --offset 5 --limit 5 --workers 2 --max-pending-review 4
```

Для теста интерфейса без сети используйте `--dry-run`. Он всё равно создаёт
кандидаты и состояние, поэтому после такого теста очистите их по инструкции из
[страницы хранения](STORAGE_AND_PORTABILITY.md).

## Markdown и темы

Ответ модели отображается как Markdown. Поддержаны заголовки, списки, жирный и
курсив, код, ссылки, зачёркивание, `==выделение==`, `++подчёркивание++` и
`<u>подчёркивание</u>`. Под редактором есть живой предварительный просмотр.
Кнопка в шапке переключает светлую и тёмную тему; выбор остаётся в браузере.
