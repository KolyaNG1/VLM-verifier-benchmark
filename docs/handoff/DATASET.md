фигуры помечены испорченными, но собрать 243 четвёрки нельзя.

Пересобрать с нуля: `python tools/build_folders.py`, проверить:
`python tools/verify_folders.py`.

## Важное про исходные данные

**Разметка порчи неполна.** Помимо 243 помеченных фигур есть **129 фигур,
которые отличаются от эталона, но метки не имеют**. Проверено сравнением md5 всех
1645 пар ML-сплита:

| Картинки | Помечена в `gold` | Штук |
|---|---|---|
| различаются | да | 228 |
| идентичны | нет | 1273 |
| различаются | **нет** | **129** |
| идентичны | да | 15 |

Среди этих 129 есть настоящая порча: у `ml_l2_fail/document_71/figure_4` вся
блок-схема зеркально отражена, текст читается справа налево, а в `gold` фигура
числится чистой. Около половины из 129 — шум пережатия (меньше 0.1% пикселей),
остальные меняются вплоть до 27% пикселей.

`unmatched_fixed.jsonl` (32 записи по ML) эти 129 не объясняет — пересечение по
паре «документ + номер фигуры» пустое.

**Следствие: непомеченные фигуры нельзя брать как заведомо чистые негативные
примеры.** Чистыми можно считать только 1273 пары с побайтовым совпадением.

Воспроизвести: `python tools/structure.py`, `python tools/diff_check.py`.

## Разметка порчи

Исходно 281 уникальная формулировка на 492 записи, свободный русский текст с
опечатками. Нормализована по двум осям в `tools/build_folders.py`.

**Действия** (`error_actions`): `delete`, `add`, `permute`, `rewire`, `geom`,
`restyle`, `replace`, `edit_value`, `edit_text`, `edit_generic`.

**Объекты** (`error_targets`): `block`, `arrow`, `axis`, `plot`, `image`, `label`.

Распределение по 201: edit_text 49, delete 48, permute 40, rewire 19, replace 16,
edit_generic 11, geom 11, add 10, edit_value 8, restyle 5.

Объекты: block 78, label 56, image 53, plot 39, arrow 27, axis 6.

Перекос неизбежен: `restyle` и `edit_value` в исходных данных почти нет.

## Привязка текста

`text_block_source` показывает качество привязки:

- `mentions` — текст прямо ссылается на фигуру, 134 пары;
- `mentions+same_page_context` — 32;
- `same_page_context` — просто текст с той же страницы, слабее, 35.

При отборе стоит отдавать приоритет `mentions`.

## Как отбирались 22 убранные

Требование бенчмарка: во фрагменте должно быть не меньше трёх критических
сущностей, иначе сэмпл невалиден для Faithfulness.

Все 223 эталона прогнаны через `z-ai/glm-4.6v` с просьбой перечислить визуальные
сущности и сущности из текста (`tools/count_entities.py`). Кандидаты с числом
сущностей меньше трёх отсмотрены глазами через `tools/review.py` и удалены.

Распределение по 207 разобранным: с 10+ сущностями 93 картинки, 9 — восемь штук,
8 — четырнадцать, 7 — семнадцать, 6 — двадцать два, 5 — двадцать, 4 — одиннадцать,
3 — четыре, меньше трёх — ноль (все убраны).

Восемь папок модель не разобрала — вернула невалидный JSON: `033`, `073`, `125`,
`151`, `159`, `181`, `186`, `206`. Они остались в наборе непроверенными.

## Известные проблемы

- Семь пар с устойчиво битым эталоном, см. `RESULTS.md`. Возможно, неверно
  подцеплен блок текста. Требуют отсмотра глазами.
- Часть caption обрезана на середине предложения. Масштаб не измерен.
- Восемь папок не прошли проверку на число сущностей.
- Домен `bt_l2_fail` (1355 фигур) в набор не входит: у него нет оригиналов.
- Юридический домен даёт ещё 57 четвёрок, в набор не включён по решению
  пользователя — берём только ML.
