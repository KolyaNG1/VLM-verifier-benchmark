# DEC_001 — Разделить протоколы и хранить эксперименты в самодостаточных каталогах

[← К журналу решений](index.md)

## Контекст

Фреймворк должен поддерживать воспроизводимый слепой тест и позднее — сравнение
сгенерированных рисунков с эталоном. Одновременная передача эталона и кандидата
меняет задачу судьи и создаёт риск оценки визуальной похожести вместо
достоверности по тексту. Просмотрщик должен читать прошлые результаты после
изменения рабочих промптов и кода.

## Рассмотренные варианты

### Один универсальный запрос с двумя картинками

- Преимущество: проще прямое сравнение.
- Недостаток: не измеряет независимую способность судьи найти смысловую ошибку
  и несовместим с ранее утверждённым слепым `orig/fail`.

### Отдельные именованные протоколы

- Преимущество: результаты методически различимы; слепой режим остаётся честным.
- Недостаток: режим с эталоном потребует отдельного входного контракта.

### Единый большой файл результатов

- Преимущество: мало файлов.
- Недостаток: трудно безопасно возобновлять, смотреть сырые ответы и частичные
  ошибки; повреждение затрагивает весь запуск.

### Каталог запуска и отдельные артефакты вызовов

- Преимущество: атомарность, аудит, простое возобновление и локальный просмотр.
- Недостаток: больше небольших файлов.

## Решение

Первая версия реализует только слепой параллельный протокол
`blind_orig_fail_parallel_v1`. Его предшественник `blind_orig_fail_v1` остаётся
именем уже записанных последовательных запусков и не смешивается с новыми.
Режим с эталоном получит отдельное имя и тип данных. Внутри одной пары `orig` и
`fail` отправляются параллельно, но отдельными запросами без общей истории.
Каждая команда `run` создаёт новый каталог со снимком конфигурации и промпта,
плоским индексом и отдельными сырыми/разобранными файлами вызовов. Изображения
не копируются; сохраняются проверенные пути, хэши и поле стороны `side`.

## Последствия

- Невозможно случайно сравнить метрики разных протоколов как один эксперимент.
- HTML-просмотрщик может открывать запуск без базы данных и сетевых запросов.
- Пара обычно завершается за время более медленного вызова, а не за сумму двух;
  стоимость не меняется.
- Для переносимого архива запуска позднее понадобится отдельная команда,
  копирующая или упаковывающая изображения.

## Пересмотр

Решение пересматривается после первого пакета из 10 пар либо если количество
малых файлов создаст измеримую проблему производительности.
