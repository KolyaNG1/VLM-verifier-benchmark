## Работа с задачами

- Новая глобальная цель или исследование получает отдельную папку задачи.
- Создание: `python scripts/docs_ctl.py create "Название задачи"`.
- Синхронизация: `python scripts/docs_ctl.py sync`.
- Полная проверка: `python scripts/docs_ctl.py check`.
- Экспорт чистой основы: `python scripts/docs_ctl.py export-template <каталог>`.

Шаблоны находятся в [каталоге шаблонов](templates/index.md).
