# Автоматическая генерация научно-популярного видео с верификацией

[← К оглавлению](index.md)

## Название

Автоматическая генерация научно-популярного видео по публикации с верификацией
достоверности.

## Назначение

Проект превращает научную статью в формате PDF или TeX в короткое видео для
специалиста, студента либо широкой аудитории. Полный процесс включает разбор
статьи, подготовку сценария, закадровый голос, создание визуальных материалов,
субтитры и автоматический монтаж.

Главная исследовательская проблема — правдоподобные, но ложные утверждения и
иллюстрации в генеративном процессе. Для неё используется двухуровневая
верификация: L1 связывает утверждения сценария с фрагментами статьи, L2 проверяет
соответствие визуального материала тексту, отсутствие галлюцинаций и пропусков
критических элементов.

## Главные цели

- Довести полный автономный процесс генерации видео до паритета с человеческим
  эталоном и до паритета либо побед против сильных генеративных моделей.
- Создать воспроизводимый бенчмарк L2 и модель-судью для научных иллюстраций.
- Измерять качество по достоверности, ясности, компактности и академическому
  стилю, отдельно сохраняя подробный аудит каждого решения.

## Границы проекта

### Входит в проект

- Извлечение структуры статьи и привязка текста, подписи и рисунка.
- Сценарии для трёх уровней аудитории.
- Генерация речи, видео, перерисованных графиков и таблиц, субтитров и монтажа.
- Верификация L1 и L2.
- Корпус эталонных и контролируемо искажённых научных рисунков.
- Эксперименты с разными VLM — визуально-языковыми моделями — и промптами,
  расчёт метрик и просмотр результатов.

### Не входит в проект

- Подмена научной экспертизы человека в высокорисковых публикациях.
- Оценка достоверности только по визуальной привлекательности.
- Передача эталонной разметки ошибок модели-судье во время слепой оценки.

## Пользователи и сценарии

- Исследователи сравнивают модели, промпты и версии полного процесса.
- Разработчик верификатора запускает одну пару, выборочный пакет или полный
  бенчмарк и изучает аудит в локальном HTML-просмотрщике.
- Специалисты по данным проверяют пары «текст — подпись — рисунок» и качество
  разметки.
- Зритель получает короткое научно-популярное видео нужного уровня сложности.

## Основные ограничения

- Результат VLM вероятностный; версия модели, промпт, параметры и сырой ответ
  должны сохраняться для воспроизводимости.
- Эталонный рисунок нельзя показывать судье в слепом диагностическом тесте
  `orig/fail`: иначе модель может искать отличия вместо проверки по тексту.
- В сравнительном бенчмарке генераторов режим с эталонным рисунком должен быть
  отделён от слепого режима и отчитываться отдельно.
- Описанная исследовательская цель корпуса — около 200 статей, поровну по
  машинному обучению и биотехнологиям. Фактический локальный снимок имеет другую
  структуру и учитывается по [проверенной странице набора](knowledge/DATASET_VERIFIER_V0.md).

## Критерии успеха

- Для каждой модели и версии промпта воспроизводимо считаются оценки 1/3/5 по
  четырём осям и общий взвешенный балл.
- Для пар доступны доли побед, ничьих и поражений по каждой оси.
- Каждый сетевой вызов имеет аудит, сырой ответ, стоимость, токены и связь с
  точной версией входа.
- Слепой тест показывает преимущество исходного рисунка над контролируемо
  искажённым и измеряет ложные срабатывания на неизменённых рисунках.
- Артефакты эксперимента можно изучить без повторного обращения к модели.
