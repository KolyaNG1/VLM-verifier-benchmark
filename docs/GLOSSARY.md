# Словарь

Добавляйте сюда только термины, которые используются в нескольких страницах.
Предметные определения должны быть краткими и ссылаться на подробную страницу.

## Термины системы документации

### Глобальная страница знаний

Тематическая страница в `docs/knowledge/`, содержащая актуальное многократно
полезное знание о проекте. История получения знания остаётся в задачах.

### Задача

Самостоятельная глобальная цель или исследование с собственными критериями
завершения, журналом и выводами.

### Источник истины

Файл или артефакт, которому отдаётся приоритет при расхождении сведений. Для
истории работы это файлы задачи, для текущего знания — глобальная тематическая
страница, для факта о поведении программы — код и результаты проверки.

### Содержательный этап

Часть работы, после которой появились новые требования, решения, выводы,
результаты, проблемы или изменения проекта, заслуживающие сохранения.
