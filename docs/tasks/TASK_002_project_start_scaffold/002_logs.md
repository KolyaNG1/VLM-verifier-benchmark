## L-20260820-02 — Экспорт очищен

**Проблема:** прежний экспорт включал `TASK_000` и историю разработки самой
системы. Это создавало лишние завершённые задачи и знания в каждом новом проекте.

**Решение:** экспорт по умолчанию изменён: он не переносит задачи, журналы,
выводы, глобальные знания, решения и источники текущего проекта.

## L-20260820-03 — Каркас создан

**Событие:** командой `export-template` создана папка `project_start/`.

**Примечание об актуальности:** каталог был доступен на момент события, но
позднее перестал находиться в рабочей области; см. актуальную пометку в
`docs/knowledge/DOCUMENTATION_ARCHITECTURE.md`.

**Результат:** каркас содержит универсальные инструкции, пустые глобальные
страницы, шаблоны, `docs/tasks/.gitkeep` и служебную программу.

## L-20260820-04 — Автономность проверена

**Проверки:**

- внутри `project_start/` выполнена полная проверка без ошибок;
- поиск не нашёл предметных терминов и ссылок на историю текущего проекта;
- в `docs/tasks/` отсутствуют задачи и журналы;
- на временной копии создана первая задача `TASK_001`;
- после создания задачи временная копия повторно прошла проверку;
- временная копия удалена.

**Результат:** каркас готов к непосредственному использованию.
