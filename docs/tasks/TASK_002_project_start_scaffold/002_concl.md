# Выводы TASK_002 — Создание чистого каркаса project_start

[← К описанию](./002_descr.md) · [Журнал](./002_logs.md)

## Краткий итог

В корне проекта создан чистый самодостаточный каркас `project_start/`. Его можно
копировать в новый каталог и сразу использовать: заполнить описание проекта и
создать первую задачу командой `python scripts/docs_ctl.py create "Название"`.

## Подтверждённые результаты и доказательства

- **Подтверждено на момент выполнения TASK_002:** каркас в `project_start/`
  содержал универсальный `AGENTS.md`, структуру `docs/`, шаблоны и
  `docs_ctl.py`. Позднее каталог перестал быть доступен в рабочей области;
  актуальное состояние отмечено в глобальной странице архитектуры.
- **Подтверждено:** в каркасе нет задач, журналов, выводов, знаний, решений и
  источников текущего проекта.
- **Подтверждено:** `python scripts/docs_ctl.py check` внутри каркаса завершается
  без ошибок и предупреждений.
- **Подтверждено:** первая задача на временной копии получила номер `TASK_001` и
  после её создания документация повторно прошла проверку.

## Полезные наблюдения

- Рабочая документация не может одновременно быть накопленной памятью проекта и
  чистой заготовкой; чистый каркас необходимо экспортировать разрешённым набором
  файлов.
- История разработки системы полезна в исходном репозитории, но в новом проекте
  должна отсутствовать.
- Пустой каталог задач сохраняется через `.gitkeep`, а первая реальная задача
  получает номер `001`.

## Проблемы и преграды

- Первоначальная версия экспорта переносила встроенную `TASK_000`.
- Нельзя было проверять чистоту только текущим дашбордом: требовалась автономная
  проверка уже скопированного дерева.

## Как решались проблемы

- Экспорт изменён на разрешённый список только универсальных файлов.
- После экспорта сводные страницы пересобираются уже внутри нового каталога.
- Каркас проверен самостоятельно и после создания пробной задачи на временной
  копии.

## Открытые вопросы

- Нет. Предметные каталоги исходного кода намеренно не создавались: их структура
  зависит от языка и типа нового проекта.

## Влияние на глобальное состояние
