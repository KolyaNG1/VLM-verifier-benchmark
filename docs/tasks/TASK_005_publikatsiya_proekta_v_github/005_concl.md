## Краткий итог

Подготовлены правила публичной поставки: проектный код и документация будут
публиковаться без данных, секретов, временных файлов и артефактов запусков.

## Подтверждённые результаты и доказательства

- README содержит путь и команду распаковки локального набора, а также инструкции
  запуска и HTML-просмотрщика.
- `.gitignore` исключает `data/`, `data.zip`, `runs/`, `tmp/`, файлы окружения
  и производные метаданные Python `*.egg-info/`.
- В исходном рабочем каталоге выполнены все 12 автономных тестов:
  `python -m unittest discover -s tests -v` завершилась успешно.
- Чистый клон не содержит набора; 4 теста, которым нужны манифест и картинки,
  ожидаемо требуют предварительно выполнить инструкцию из README.
