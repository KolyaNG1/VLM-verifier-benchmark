# TASK_005 — Публикация проекта в GitHub

[← К дашборду](../../TASKS_DASHBOARD.md)

## Навигация

- [Журнал](./005_logs.md)
- [Выводы](./005_concl.md)

## Цель

Опубликовать код, тесты, промпты, HTML-просмотрщик, документацию и `AGENTS.md`
в репозитории `KolyaNG1/VLM-verifier-benchmark`, исключив набор данных и
производные локальные файлы.

## Границы

### Входит

- Клонирование указанного GitHub-репозитория, перенос файлов проекта и отправка
  изменений в основную ветку.
- Явное исключение набора `data/`, архивов данных, ключей, результатов запусков
  и временных файлов.
- Обновление README: установка, размещение набора, проверки, реальные запуски и
  HTML-просмотрщик.
- Публикация всей проектной документации и `AGENTS.md`.

### Не входит

- Публикация, загрузка или передача набора данных, архивов, ключей и результатов
  платных запусков.

## Требования пользователя

- 2026-08-20 — клонировать `https://github.com/KolyaNG1/VLM-verifier-benchmark`,
  добавить весь проект кроме данных и отправить изменения в GitHub.
- 2026-08-20 — в README указать, куда и как подгружать данные, и описать
  HTML-просмотрщик и запуск проекта.
- 2026-08-20 — добавить всю документацию и `AGENTS.md`.
- 2026-08-20 — продолжение: отправить в GitHub новые изменения пользователя.

Добавляйте сюда каждое существенное уточнение пользователя с датой.

## Критерии завершения

- [x] Удалённый репозиторий содержит последние изменения пользователя.
- [x] Данные, архивы, ключи, результаты запусков и временные файлы исключены.
- [x] README содержит проверенные инструкции установки, загрузки данных,
  запуска и HTML-просмотрщика.
- [x] Выводы и проблемы описаны.
- [x] Глобальные знания и решения обновлены при необходимости.
- [x] `python scripts/docs_ctl.py check` завершился без ошибок.

## План

1. Проверить структуру проекта и правила хранения данных.
2. Обновить README и правила исключения файлов.
3. Клонировать репозиторий, перенести разрешённые материалы и отправить их.
4. Проверить состав удалённой ветки и обновить документацию.

## Допущения и ограничения

- Набор `verifier_v0` пользователь получает из разрешённого источника; ссылка
  для публичного скачивания в задаче не предоставлена.
- Основная ветка целевого репозитория и право отправки изменений доступны через
  локальную авторизацию Git.

## Рассмотренные варианты и обоснования

Сохраняйте краткие причины выбора, альтернативы и проверяемые допущения, но не
скрытое пошаговое рассуждение модели.
