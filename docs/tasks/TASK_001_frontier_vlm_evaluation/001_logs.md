## L-20260820-02 — Определена роль фронтирных моделей

**Событие:** сформулирована матрица «модель-судья × промпт» для проверок
`orig` против `fail_pic`.

**Результат:** фронтирные генераторы и фронтирные модели-судьи разделены на
два разных эксперимента. Для верификатора сравниваются специализированный
промпт и общий промпт на одних и тех же моделях; сильные внешние модели нужны
также для независимой проверки.

**Основание:** пользовательское требование доказать преимущество решения над
прямой оценкой картинки.

**Связанные материалы:** [выводы](./001_concl.md),
[глобальное знание](../../knowledge/VLM_VERIFIER_EVALUATION.md).

## L-20260820-03 — Уточнён обязательный базовый эксперимент

**Событие:** подтверждено, что фронтирная модель-судья с общим промптом должна
входить в разработку верификатора как обязательная базовая линия.

**Следствие:** одного сравнения с такой линией недостаточно; для доказательства
вклада промпта также нужен запуск выбранной модели-судьи с тем же общим
промптом.
