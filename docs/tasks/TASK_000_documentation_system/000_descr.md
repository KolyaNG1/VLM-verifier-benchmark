## Цель

Создать универсальную начальную систему документации, которую можно копировать
в программные, исследовательские и связанные с данными проекты. Система должна
поддерживать постоянную общую память нескольких чатов и автоматически сохранять
результаты работы и исследований.

## Границы

### Входит

- Универсальный корневой `AGENTS.md` без предметной информации.
- Дерево связанных страниц с входом через `docs/index.md`.
- Обязательные файлы описания, журнала и выводов для каждой задачи.
- Дашборд статусов и связей всех задач.
- Глобальное текущее состояние и тематические страницы знаний.
- Обязательное оформление любого самостоятельного исследования как задачи.
- Перенос многократно полезных исследовательских выводов в глобальные страницы.
- Поддержка параллельных чатов без совпадения номеров и потери общих обновлений.
- Шаблоны, автоматическая синхронизация и проверка документации.
- Экспорт чистой основы без предметных задач уже работающего проекта.
- Сохранение прежних проектных материалов вне универсальной папки `docs/`.

### Не входит

- Предметное описание какого-либо конкретного проекта.
- Автоматический смысловой вывод из кода без работы агента.
- Использование внешней базы данных или векторного поиска.
- Обязательное использование субагентов.

## Требования пользователя

- 2026-08-20 — документация разбивается на несколько связанных файлов; корнем
  дерева ссылок является `index.md`.
- 2026-08-20 — каждый новый чат соответствует новой глобальной задаче; задачи
  также могут создаваться внутри чата.
- 2026-08-20 — папка задачи содержит `*_descr.md`, `*_logs.md` и `*_concl.md`;
  разрешены дополнительные связанные файлы.
- 2026-08-20 — описание хранит требования и уточнения, журнал — ход работы с
  оглавлением важных событий, выводы — промежуточные и финальные результаты,
  проблемы, преграды и способы решения.
- 2026-08-20 — дашборд содержит краткое описание, статус, ссылки и связи всех
  задач.
- 2026-08-20 — `CURRENT_STATE.md` компилирует актуальное состояние проекта и
  ссылается на задачи и глобальные подробные страницы.
- 2026-08-20 — любое самостоятельное исследование является задачей, даже если
  код и данные не меняются.
- 2026-08-20 — исследование структуры, архитектуры или датасета должно сохранять
  все полезные наблюдения в выводах задачи, а многократно полезные сведения — в
  отдельных глобальных страницах знаний.
- 2026-08-20 — все страницы должны оставаться актуальными и автоматически
  обновляться.
- 2026-08-20 — система должна быть универсальной основой для копирования между
  проектами, в основном программными.
- 2026-08-20 — необходимо проверить, что пользовательские требования и
  дополнительные предложенные механики явно закреплены в инструкциях.

## Критерии завершения

- [x] Корневой `AGENTS.md` не содержит сведений конкретного проекта.
- [x] Созданы все глобальные страницы, разделы и шаблоны.
- [x] Исследования прямо объявлены отдельным видом задач.
- [x] Определён перенос локальных исследовательских выводов в глобальные знания.
- [x] Реализованы безопасная выдача номеров, синхронизация и проверка.
- [x] Старые материалы сохранены вне универсальной документации.
- [x] Создание самой системы оформлено задачей.
- [x] Автоматическая проверка документации пройдена.
- [x] Экспорт чистой основы проверен на временной копии.

## Рассмотренные варианты и обоснования

### Один большой `AGENTS.md`

Отклонён: он дублировал бы знания проекта, быстро рос и усложнял навигацию.

### Короткий `AGENTS.md` и подробный регламент

Принят: обязательные правила загружаются всегда, а подробности остаются в
связанной документации.

### Ручное обновление общих таблиц

Отклонено для параллельной работы: два чата могут выдать один номер или
перезаписать изменения друг друга.

### Автоматически собираемые общие страницы

Принято: источниками истины остаются локальные файлы, а центральные страницы
строятся под файловой блокировкой.
