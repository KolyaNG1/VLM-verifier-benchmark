# TASK_004 — Фреймворк экспериментов с VLM

[← К дашборду](../../TASKS_DASHBOARD.md)

## Навигация

- [Журнал](./004_logs.md)

## Цель

Реализовать воспроизводимый фреймворк, который для выбранной модели через
OpenRouter независимо оценивает исходную и изменённую картинку по одному
шаблону промпта, сохраняет полный аудит и подготавливает артефакты для будущего
просмотрщика результатов.

## Границы

### Входит

- Утилита загрузки только корректных пар ML-поднабора.
- Шаблоны системных промптов в Markdown с повторяемыми вставками подписи,
  текста и изображения.
- Независимые вызовы VLM для `orig_pic` и `fail_pic` с одинаковым шаблоном.
- Извлечение итогового балла и аудита, запись ответа и метаданных OpenRouter.
- Версионирование промптов по имени и содержимому файла; структура артефактов,
  удобная для будущего HTML-просмотрщика.
- Пакетные и выборочные запуски по количеству, идентификаторам и путям.
- Локальный HTML-просмотрщик с отдельными HTML, CSS и JavaScript.

### Не входит

- Выбор окончательных моделей, содержательное совершенствование промпта и
  полномасштабный прогон всего набора в рамках первой реализации.
- Передача оригинальной картинки в тот же вызов VLM, что и изменённой: оценки
  должны быть независимыми и слепыми.
- Режим сравнения Human / Our Pipeline / Frontier с одновременной передачей
  эталона и кандидата; он проектируется отдельно после слепого `orig/fail`.

## Требования пользователя

- 2026-08-20 — создать фреймворк тестирования разных VLM и разных системных

  `<image>`.

- 2026-08-20 — загрузчик набора должен возвращать только существующие нужные

## Допущения и ограничения

- Существующая `src/test_openrouter_vlm.py` подтверждает способ загрузки
  локального изображения и вызова OpenRouter, но является пробным скриптом, а
  не архитектурой фреймворка.
- `gold` разрешено использовать только для оценки уже полученных результатов,
  а не передавать судье.
- Первая версия использует включающие границы `Coverage ≥ 0.60/0.80`; пороги и
  веса являются частью конфигурации запуска.
- Мягкий предел стоимости по умолчанию — 5 USD. Перед превышением новые вызовы
  не запускаются; полученные артефакты остаются пригодны для продолжения.

## Рассмотренные варианты и обоснования

- **Предложение:** хранить один каталог на запуск эксперимента, а в нём
  неизменяемый `experiment.json`, копию промпта, построчный `results.jsonl` и
  отдельные папки примеров с исходным запросом, сыром ответом, разобранным
  ответом и ссылками на картинки. Это позволяет просмотрщику читать локальные
  файлы без повторных запросов.
- **Риск:** настоящее изображение передаётся OpenRouter отдельной
  мультимодальной частью сообщения. Вставка `<image>` в произвольную позицию
  Markdown-шаблона требует выбрать между переносимым системным сообщением и
  составным пользовательским сообщением.
- **Решение пользователя:** использовать составное пользовательское сообщение;
  постоянная системная строка задаёт только роль и обязательный JSON.
- **Решение пользователя:** основной набор по умолчанию — 243 искажённые пары,
  модель — `z-ai/glm-4.6v`, HTML-просмотрщик входит в первую версию.
- **Предложение:** слепой диагностический режим и будущий режим с эталоном
  получают разные имена протокола и не смешиваются в одной агрегации.
