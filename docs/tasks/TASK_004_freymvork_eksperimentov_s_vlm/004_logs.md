**Результат:** оба вызова успешно вернули валидный JSON, итоговый каталог —
`runs/20260820T105145Z__z-ai_glm-4.6v__v001_baseline__97d3bd7b`. Общая
стоимость двух вызовов — `0.00625178 USD`. Для обеих сторон получены оценки

блоков», однако судья сообщил `U=0`, `M=0`, Coverage `1.0` и не обнаружил
изменение. Это единичное наблюдение для настройки промпта, а не агрегированная
метрика качества модели.
