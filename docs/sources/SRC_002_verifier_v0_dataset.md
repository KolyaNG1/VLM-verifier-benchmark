# SRC_002 — Локальный набор verifier_v0

[← К каталогу источников](index.md)

## Происхождение

- Владелец: локальные материалы проекта; внешний автор и дата публикации в
  доступных файлах явно не зафиксированы.
- Дата доступа: 2026-08-20.
- Путь: `data/data/verifier_v0/`.

## Содержание

Содержит JSONL-манифесты, PNG-рисунки, метаданные статей и свободнотекстовые
описания контролируемых изменений. Главные для ML-поднабора файлы:
`manifest_ml_l2_fail.jsonl`, `manifest_ml_orig.jsonl`,
`hints_ml_l2_fail.json`, `figures/ml_l2_fail/` и `figures/ml_orig/`.

## Область применимости и ограничения

- Подтверждает фактическую структуру, количества, пути и значения разметки,
  описанные в [глобальном знании о наборе](../knowledge/DATASET_VERIFIER_V0.md).
- Не подтверждает внешнее происхождение набора, правила его разбиения на
  обучение и тест либо смысл каждой свободнотекстовой ошибки без отдельного
  исследования.
