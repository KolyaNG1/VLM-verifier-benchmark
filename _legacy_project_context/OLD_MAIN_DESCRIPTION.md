Я работаю над проектом по генерации видео по научной статье. Вот описание:
Автоматическая генерация научно-популярного видео по публикации с верификацией достоверности
Мы разрабатываем пайплайн, превращающий научную статью (PDF/TeX) в короткое видео: разбор структуры публикации, сценарий под три уровня аудитории (специалист, студент, широкая аудитория), закадровый голос, генеративное видео, перерисованные графики и таблицы, субтитры и автоматический монтаж. Рабочий прототип уже собран и производит видео end-to-end.
Ключевая проблема генеративных пайплайнов — правдоподобные, но ложные утверждения и иллюстрации. Поэтому научное ядро проекта — двухуровневая верификация. L1 проверяет фактологию сценария: каждое утверждение 	прослеживается до конкретного фрагмента исходной статьи. L2 проверяет визуальный контент: соответствует ли сгенерированная иллюстрация тексту, нет ли галлюцинаций и пропущенных критических элементов.
Сейчас основной фокус — бенчмарк и верификатор L2. Собран корпус из 200 статей (100 по ML, 100 по биотехнологиям), где для каждой есть оригинальные иллюстрации и версии с контролируемо внесёнными искажениями. Оценка ведётся судьёй-VLM по четырём осям — faithfulness, clarity, compactness, style — против эталонных рисунков из статей и против фронтирных генеративных моделей. Результаты планируем подать на воркшопы AI4S-Bench (ICDM 2026) и AI for Meta-Science (NeurIPS 2026).
От студентов (2 человека). Первый — эксперименты с VLM: промпты для судьи и генератора, прогон фронтирных моделей на бенчмарке, сбор метрик. Второй — данные: разметка эталонных пар «текстовый блок — caption — рисунок», контроль качества разметки, расширение корпуса. Нужны Python, опыт с API/локальными LLM-VLM, аккуратность в экспериментах.
